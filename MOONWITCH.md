# Moonwitch

Moonwitch is an Android-focused Nintendo Switch emulator fork derived from STORM EDEN / Eden.

Initial base: STORM EDEN 4.7.4, commit `6da6709e28e240a17df138b3bee57f93aa75526d`.

## Initial goals

- Independent Android application identity (`dev.moonwitch.emulator`).
- Original Moonwitch branding and UI direction.
- Diagnose and fix intermittent Android Vulkan initialization failures.
- Investigate The Legend of Zelda: Tears of the Kingdom foliage/instancing corruption.
- Investigate UltraCam / TOTK Optimizer compatibility crashes.
- Preserve upstream improvements while keeping Moonwitch-specific Android fixes isolated and reviewable.
